🚨 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════

❌ No puedo acceder a http://TU_IP:3000
   → Verificar firewall: ufw status
   → Abrir puerto: ufw allow 3000/tcp
   → Reiniciar: docker-compose -f docker-compose-nossl.yml restart

❌ Panel muestra error
   → Ver logs: docker logs nexo_control_panel
   → Reiniciar: docker restart nexo_control_panel

❌ n8n no carga
   → Ver logs: cd instances/cliente1 && ./manage.sh logs
   → Reiniciar: ./manage.sh restart

❌ Puerto en uso
   → Ver qué lo usa: lsof -i :5678
   → Matar proceso: kill -9 [PID]
